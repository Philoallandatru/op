# 第三轮 10 份误导答卷的取证与处置复盘

逐条对照[候选原答](../field-usable-v3/candidate-reviewed.jsonl)、[冻结判据](../field-usable-v3/bank-as-tested.jsonl)和本地保留的 Pi 原始消息。页号命中只说明找到候选页。只有当规范句子或寄存器行实际进入用户预取片段或工具结果时，才算模型收到该项证据。本表按导致现场动作错误的主要句子归因。

| 题 | 导致错误处置的句子 | 当时实际收到的证据 | 现场处置 |
| --- | --- | --- | --- |
| SSD-F3-03 时间戳 | 把控制器差值作停顿下界，或用 SYNC=1 判定确有停顿。 | **证据已到，推断越界。** NVMe pp.402–403 整页说明复位或保存值可使时间戳倒退，计数也只是可能暂停。 | 保留记录。用采集端单调时间和同一次事件记录做关联、去重与计时。控制器读数无法给跨复位停顿定下界。 |
| SSD-F3-04 Saved | 支持保存且 Saved=Default 就按未持久化结案。 | **证据已到，反推错误。** NVMe pp.221–223 已给出 Saved 的回退、成功保存的定义和可保存能力。答卷末尾也承认已保存值可恰等于默认值。 | 拒签该导出证明。查同一 FID 的历史请求、Save 位、实写值和匹配成功完成。找不到就保留未证实。 |
| SSD-F3-05 SMART | CW=0 且备用容量充足即可撤故障单。 | **证据已到，追加结论越界。** NVMe pp.231–232 足以判断 PUSED 的字段语义，并限定各告警位。字段正常没有给出覆盖所有故障的检查。 | 撤销两条导入规则。255 按饱和编码记录；若已有故障单，依据该单自己的独立证据处理。 |
| SSD-F3-06 易失缓存 | 掉电试验发现已完成写丢失即按盘故障处理。 | **证据已到，归责越界。** NVMe p.398 返回行为和等效非易失的说明都进入预取或搜索。它们只支持当前协议符合性，不为跨层掉电试验提供归因。 | 撤销基于 FID 06h 返回码的判盘规则。整机持久性待单独验收，按同次完成及断电边界逐层定位。 |
| SSD-F3-07 VPD | 两个重读结果都不同，所以已可排除旧错误来自 VPD。 | **证据已到，反推错误。** PCIe p.980 整页写明旧交错读取不具定义。 | 作废旧样本，串行捕获同地址握手再登记。新值只支持本次有效采样，旧错误来源仍需旧采集链路记录。 |
| SSD-F3-08 插槽按钮 | 以 Command Completed 为软件下线和拔除的硬门槛。 | **部分取证加处置错误。** 第二次按键取消与闪烁不可拔都已取得。搜索虽命中 p.749，回给模型的摘录没有该位的关键语义和可硬连为零的限制。整页读取停在 p.747。 | 拒绝本次拔出。按实际插槽的热插拔流程取得软件与平台放行。Command Completed 只用于控制器命令握手。 |
| SSD-F3-09 DPC | 把 DPC RP Busy 写为 bit 5，让脚本轮询该位。 | **证据已到，字段绑定错误。** PCIe p.958 整页和预取都有 `4` 紧邻字段描述；p.526 同时支持 Busy 门槛。p.527 错误完成条款未回到模型，但并非误读位号的原因。 | 保持 containment，按 DPC Status 的 bit 4 确认 Busy 清零并核对其他释放条件。恢复后枚举有响应也只证明当前状态。 |
| SSD-F3-10 功率预算 | 越界未定义，且 Thermal 作为电源轨叠加。 | **部分取证加处置错误。** p.830 是命中页，摘录没回送越界全零条件；p.832 已整页返回 Thermal 与供电轨的区别。 | 对每块设备各自解码记录，越界当作无记录，按实际供电轨核算。Thermal 如另有上报则单列，不能重复叠加。 |
| SSD-F3-11 VC 协商 | 从 VC Resource Capability 读 VC ID。 | **部分取证加处置错误。** 两端 Pending 条件已返回。p.897 返回片段没同时给出 VC Resource Control、`26:24` 和 VC ID，模型未整页核验就指定了寄存器。 | 维持 VC0，核对同链路上同一 VC 的两端 Pending。确需锚定 VC ID 时从 VC Resource Control 读取。 |
| SSD-F3-12 分段 Completion | 把非成功的末尾规则写成只有失败才是末尾；AER 位为 0 直接派盘。 | **核心证据已到，规则反向。** PCIe p.204 预取包含收齐才完成、超时后可保留或丢弃部分数据。原答把成功路径改成了仅失败可结束；清零快照也不足以定位故障层。 | 拒绝首段即整段和当前归因。按身份及字节覆盖核对完整请求。保留采样并记录超时后的部分数据处置，不能当作完整描述。 |

7 份在关键动作上已拿到所需条款，3 份只拿到部分条款并据此给出超出证据的处置。取证升级用字面短语在命中页及相邻页抽取原始条款，补查寄存器名、前提和续页；skill 同时要求核对条件方向、同一对象和动作授权。两项都从旧题归因得到，第四轮题面未用于修改。
