# 第四轮留出试验

先逐题检查第三轮 10 份误导答卷的原始检索和读页结果。7 份在关键动作上已收到所需条款，3 份有证据缺口并继续给出错误处置。[逐题复盘](ten-answer-audit.md)

调查之后冻结两种配置。候选增加了字面短语和相邻页核验工具，并用 skill 约束证据方向、动作范围和精确位号。12 道模拟题来自 12 个此前未用的故障族。两版都使用 Pi 1.5.2、同一 DeepSeek Flash 路由、相同的语料和 120 秒时限。8 次取证额度均包含两次预取。两个版本收到相同的 `decision-audit` 作答提示。按题交叉投放，只保留首答。两位模型独立匿名评分，第三位在隐藏组别的条件下裁定分歧。[冻结配置](registration.json) · [评审记录说明](review-protocol.json)

| 指标 | 第三轮配置 | 第四轮配置 |
| --- | ---: | ---: |
| 原样可用 / 计划 | 0/12 | 0/12 |
| 可能误导 / 交卷 | 12/12 | 12/12 |
| 严格评分通过 | 12/12 | 9/12 |
| 交卷 | 12/12 | 12/12 |

候选进行了 5 次成功的相邻页核验调用。两位初评在 21/24 份答卷上的可用性标签一致。12 份答卷在标签、判据分或否决项上存在分歧，均在揭盲前裁定。两组的主指标均未改进。[归档对照报告](../../reports/field-usable-v4.json) · [裁定标签](ratings-final.jsonl)

许多原答能正确拒绝当前请求，却在后段把一次快照、返回码或控制位升级为充分归因或放行条件。例如 SSD-F4-10 已正确指出端口能力位不足以批准 P2P AtomicOp，却用 UR 加状态位将原因归到特定端口对。现有运行提示仍要求扩展到多个后续结果，抵消了 skill 对证据已足时收束的要求。第五轮将运行提示限制为当前处置、直接证据和必要的一条只读核验，另选新题检验。[第五轮](../field-usable-v5/README.md)
