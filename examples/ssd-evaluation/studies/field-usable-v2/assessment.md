# 现场可用性盲评约定

本轮在候选配置投放前固定以下口径。每题每组只计首次运行，超过 120 秒未交出最终答案也占分母。选题、题面哈希和组别顺序见 [第二轮报告](../../reports/field-usable-v2.json)。

主指标为工程师可以原样据以决定、复测或交接的答卷数，除以每组全部 12 个计划问题。每份答卷取以下一种标签。

| 标签 | 判定 |
| --- | --- |
| ready · 原样可用 | 当前决定、依据、作用对象和影响决定的条件正确。如果需要复测，现场同事知道查什么，以及结果如何改变处置。直接拒签或说明当前可得结论有时已经足够。措辞偏好、无关紧要的省略和与参考答案等效的解法均可接受。 |
| revise · 需修改 | 处置方向可保留，但缺一项会阻碍交接的条件、证据定位或能区分原因的观测。工程师需要补写后才能用。 |
| misleading · 可能误导 | 全文有一项具体判断足以让工程师查错对象、把未证实的原因当事实、误阻断或错误放行、执行越权或范围不清的变更。指出原句及其后果。 |
| no_answer · 未交卷 | 时限内没有最终答复。 |

另按题库原来的关键项给 0、0.5、1 分，记录命中的预设否决项序号。严格通过沿用原计分程序。预设表外的处置错误进入全文可用性判定及评语。现场动作可执行且正确时，不能因为形式、篇幅、未采用参考解法或特定组偏爱的文风而降级。

两位评审各自查看全部随机编号的答卷、题面和既定判据，可以复核规范原文。评审材料无组名、工具调用或耗时。两份独立判断落盘后，在仍隐藏组别时裁决可用性和评分分歧。裁决优先看具体说法能否改变处置以及原文和观测是否支持。保存初评、复评、最终判断及分歧理由。

揭盲后逐题配对统计原样可用的改善、退步和持平。报告绝对百分点差及基于不一致对的双侧精确 McNemar 检验。次指标为可能误导、交卷、严格通过、耗时和证据调用。记录实际载入 skill 的证据与工具故障。出现异常保留首次结果并注明。此次联合干预只估计两个改动一起启用的效果。
