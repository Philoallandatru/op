# 第八轮响应时间与交付质量

## 第七轮耗时拆解

| 完成交卷的中位耗时 | 第六轮配置 | 第七轮配置 |
| --- | ---: | ---: |
| 端到端 | 29.21 秒 | 49.35 秒 |
| 检索 | 0.44 秒 | 0.41 秒 |
| 起草 | 21.61 秒 | 34.66 秒 |
| 复核签发 | 7.41 秒 | 13.56 秒 |

历史研究没有分阶段计时，因此阶段值来自 Windows 文件创建与最后写入时间、Pi 的取证工具完成事件。检索估算包含预取和合并后的工具等待，起草扣除了工具等待。工具发起前的模型推理留在模型阶段。合并工具等待使用工具结果时间戳和报告的持续时间，相互重叠的区间只计一次。每一行独立计算中位数。[逐题日志统计](round-7-latency.json)

第七轮每题交互工具调用数的中位数从 2 增到 3.5。拿旧题 F7-04、05、07、15 做诊断，采用短草稿和合并取证的版本仍有多轮补查，四题中两题变慢。让原签发模型直接核对原文后交付，在相同四题上均交卷，耗时为 12.95、25.07、31.57、26.01 秒。旧题只用于诊断和方案选择。

## 盲测方法

配置先冻结，再根据 NVMe Base 2.1 和 PCIe Base 5.0 Version 1.0 设计 16 个未参与调优的合成工单。各协议 8 题，32 个原文定位均已与两份 PDF 核对。两套配置各先答 8 题，复用相同语料、预取、120 秒时限和 8 次取证预算。基线由 DeepSeek Flash 起草、Codex Sol 核对后签发。候选由同一签发模型一次完成补证、核对和签发，保留原有的必要条件、适用范围、历史归因和输出结构。MCP 的 `find_spec_conditions` 合并关键词查找和原文窗口读取。答题进程只收到题面和观测，两位评审从匿名答卷独立评判，分歧在揭盲前交第三位裁定。[注册](registration.json) · [留出题](questions.jsonl) · [评审](review-protocol.json)

新一轮使用单调时钟计预取、模型进程和独立复核的实际时间。检索为预取与工具等待，重叠等待只计一次。候选独立起草记 0，生成和核对均归签发。其余本地准备归其他。工作台对已交卷且有测量的答卷取中位数；处置条件完整按冻结判据 C2 全部满足计入，分母与原样可用一样是计划题。误导以已交卷为分母，同时保留同题均交卷的对照。

## 盲测结果

| 指标 | 第七轮配置 | 第八轮配置 |
| --- | ---: | ---: |
| 端到端中位数 | 62.63 秒 | 24.70 秒 |
| 检索中位数 | 0.42 秒 | 0.46 秒 |
| 独立起草中位数 | 48.80 秒 | 0 秒 |
| 签发中位数 | 13.82 秒 | 23.41 秒 |
| 处置条件完整 / 计划 | 13/16 | 15/16 |
| 原样可用 / 计划 | 9/16 | 13/16 |
| 可能误导 / 交卷 | 2/16 | 1/16 |

两边均交齐 16 题，无 MCP 初始化异常。16 个同题对照均提速，配对耗时节省的中位数为 35.19 秒。6 道题转为原样可用，2 道从原样可用转为需修改。4 道历史题的原样可用数从 0 提升到 3，其中 1 道候选答卷可能误导。两位初评对 21/32 份给出同一可用性标签，11 份标签或判据意见分歧在揭盲前裁定。题目合成、评审由模型完成，样本量为 16。[指标](metrics.json) · [基线答卷与评判](baseline-reviewed.jsonl) · [候选](candidate-reviewed.jsonl) · [裁定](ratings-final.jsonl)

候选三份未达原样可用的原因如下。

- F8-02 给出一次门铃发布的正确处置，验收步骤遗漏两条 fused 命令分别有 CQE。
- F8-05 引用了 NVMe PDF p.445 的容量公式，将其用作实际门铃槽位的检查。Figure 486 同页分别列出 SQ Tail 和 CQ Head 的偏移。验收需检查实际使用的最大条目末端仍在页内。单独用正文公式作上界可能放行越界布局。
- F8-15 选对了 MSI-X Table 和有效 MSI 向量，遗漏实际要写入相应 Vector Control 的高两字节。

## 复现

使用准备好的本地 PDF 语料、Pi 和配置好的 `magpie` 提供方。归档可脱离模型重新导出工作台 JSON。

```powershell
$kit = 'examples/ssd-evaluation'
python -X utf8 "$kit/export_workbench.py" "$kit/studies/field-usable-v8/workbench-manifest.json" --output "$kit/.local/replay-v8.json"
python -X utf8 "$kit/studies/field-usable-v6/summarize.py" "$kit/.local/replay-v8.json" --bank "$kit/scenarios/field-engineering-v8.jsonl"
```
