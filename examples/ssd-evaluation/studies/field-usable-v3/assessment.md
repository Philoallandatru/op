# 本轮判定与统计约定

投放前固定两项主指标。**原样可用率**是 ready / 计划提问数；这要求工程师可以据完整答卷作当前决定。**误导率**是 misleading / 已交卷数；这衡量实际出现的回答有多大比例会引人采取错误行动。另报 misleading / 计划数、两组完答数及超时，防止漏答使风险看起来更低。

使用[上轮相同的四档标准](../field-usable-v2/assessment.md)。评审按当前任务决定，而非按答案长度或是否逐值枚举评分。如果一个答复直接解决本题，允许省略不会改变行动的其他状态。不能因为作者用了表格、添加很多兜底条款或列了规范号就给分。误导须指明原句、错误前提和合理可预见的现场后果。需要补写才能执行、暂时还不会导向错误处置的缺口标为需修改。无最终答复使用 no_answer，并保留计划分母。

两位独立评审只看随机编号的原答、问题与事前冻结的判据、参考答案和真实规范定位。每份按四档标签和原 rubric 分别判定。评审独立落盘后，仍在隐藏组别的条件下核对分歧并保存裁决与理由；冻结最终评分再揭盲。

报告原样可用率与百分点差，以及在全部配对问题上由不可用转为可用、反向转换、未改变的数量。对误导单独报告双方都已交卷的共同子集、由误导转为非误导及反向变化，逐组分母保留原样。两项分别给出基于对应不一致对的精确双侧 McNemar 检验，仅用于交代这个小样本可以支持到什么程度。若双方均已交卷的题数为零则该项不估计。严格评分、工具实用与时延作为诊断。一次留出测量完成后，这些题只适合回归，不据它们修改候选再计算本轮成绩。
