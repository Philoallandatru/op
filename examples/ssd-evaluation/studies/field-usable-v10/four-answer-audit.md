# 第九轮四份答卷的现场验收缺口

四题的 C2 处置条件都已满分。三题的 C3 核验未满分。F9-11 的 C3 满分，揭盲前的裁决在判据之外识别出应用替代映射的必要验证。保留原判与原答。[第九轮候选答卷](../field-usable-v9/candidate-reviewed.jsonl)

| 旧题 | 要测或确认的对象 | 要看的现场记录 | 足以签发的标准 |
| --- | --- | --- | --- |
| F9-03 | 安全配置下最高编号 SQ Tail 和 CQ Head 在两块缓冲页的实际条目 | 同次配置和成功的 Admin CQE、当前页基址、队列 ID、Shadow Doorbell 与 EventIdx 两页的地址和值及访问轨迹 | 先确认正文和槽位边界均合法，再实测拟签范围内最远的两项。两页偏移、条目和值对应本次队列活动，旧低编号记录仅覆盖实测范围。 |
| F9-09 | 一次 fused 操作的首条和次条状态及其含义 | 同次两条原始 CQE 的 SCT/SC、提交关联信息和适用命令集的 Fused Operation 条款 | 每条 CQE 对上自己的命令并符合适用状态组合。归档首条实测状态时，记录和命令集条款都要齐全。 |
| F9-11 | 应用对目标请求所用短 Steering Tag 的接受性，以及写入的字段 | 获准的应用或平台映射、Function/向量标识、写入和 Vector Control 的读回记录 | 映射认可拟用的替代值才修改 ST Lower。核对写后值和保留的上字节及其他位。 |
| F9-15 | 目标 MSI-X 表项的改写时序，以及实际解掩后的同一次消息 | 有效掩蔽、地址与 32 位数据写入和读回、实际解掩及可归属于该表项的 DWORD Memory Write | 改写和读回应在有效掩蔽期间，放行时目标消息的目的地址和完整 32 位数据须同时匹配新值。 |

最终配置重放四道旧题，四份均生成现场验收记录。复跑中发现模型偶尔会在 JSON 前加简短说明。解析器在能识别单个完整对象且尾部合规时提取结构化内容，减少一份事实正确的答卷因开头说明无法交卷的风险。[回归答卷](regression-replay.jsonl)
