# PCIe 与 NVMe 规范问答实验

2026-11-24。实验覆盖 PCI Express Base 5.0 Version 1.0 与 NVM Express Base 2.1。推荐先在规范问答 MCP 使用 `domain`，按协议和版本搜索原文段落、返回文件页码，并保留整页读取。它在留出集的双问全证据通过数与复杂融合持平，逐问找全证据 118/170，本机查询 P95 为 13.11 ms。通用知识检索可继续提供概念入口。[实验用 MCP](evidence_mcp.py) · [检索器](retrieval_trial.py)

## 两轮排序实验

把原问题和改写分别交给检索器，每次只给协议和题面，最多取五页。核心指标为一道题的**两种问法都在前五找全全部金标页**。逐问找全只要求当次表述找全。MRR@5 按首个命中页的倒数排名计分。7 道需补证题另做问答评审，检索分母为开发 78 题、留出 85 题。每个协议的原文池独立，版本和协议均为已知输入。

| 方案 | 开发双问 / 78 | 留出双问 / 85 | 留出逐问找全 / 170 | 留出 MRR@5 | 本机 P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 现有概念检索后沿显式原文页链接 | 7 | 18 | 44 | 0.143 | 40.38 ms |
| 整页 BM25 | 33 | 32 | 98 | 0.402 | 1.18 ms |
| 整页 BM25 加中英术语和短语 | 42 | 39 | 112 | 0.458 | 1.45 ms |
| 中英术语、章节权重、90 词段落 `domain` | 44 | **45** | **118** | 0.491 | 13.11 ms |
| 整页与段落等权融合 `fusion` | 47 | 43 | 116 | **0.495** | 15.86 ms |
| 再挖掘术语、缩写和相邻页并加权 `refined` | **51** | **45** | 117 | 0.473 | 36.01 ms |

第一轮固定比较前五种方案。第二轮只使用开发结果探索 48 组融合与邻页权重，选定一套两个协议共用的参数，冻结检索实现后运行留出。表中使用复核题面后的定稿。每个查询与模式在本机测一次，时延涵盖 Python 检索调用，不含进程启动、建索引和模型推理。概念基线先取前五个概念，再按正文链接读出页号；PCIe 概念的文件级引用无法用这一规则定位原文页，所以这条路径在 PCIe 留出集为 0/42。

`domain` 在 PCIe 为 19/42，在 NVMe 为 26/43；`refined` 分别为 17/42 和 28/43。两者总数相同，逐题有五得五失。以 PCIe Completion Timeout 的 PCIE50-035 为例，段落方案两种问法都把第 204 页排第一，复杂融合两次均漏出前五。当前结论适用于本题库与这些本地词法方案。若计划按协议切换检索器，应在另取的整章上盲验。当前这批留出题已用于报告，往后适合作为回归集。[逐题回归参照](reference/domain-test.json)

## 从命中页到可引用答案

1. 在留出集 170 个问法中，`domain` 有 **118** 个在前五找全必需页，只有 **66** 个在每个命中页返回的一段预览里包含全部标注短锚。PCIe 分别为 52/84 和 35/84，NVMe 分别为 66/86 和 31/86。这是严格字符串指标；同页其他有效表述和支持答案的同义段落需要单独评审。留出的 4 道多页题共有 8 个问法，`domain` 只有 2/8 次找全页。
2. 真实 stdio MCP 已在两个协议上跑过搜索、读页和原文片段回查。独立 Pi CLI 1.5.2 用 `auto/deepseek-v4.1-flash`、thinking off、`domain` 做了三道 NVMe 小样本。每题新进程、服务端预算 6 次、120 秒。模型只收到题面和工具，没有金标页号。以下只评所列断言，未进行对所有附带论述的逐句审定。

| Pi 题号 | 结果 | 服务端检索 / 读页 | 时间 |
| --- | --- | ---: | ---: |
| NB21-046，HMB 重复启停 | 第一次搜索漏掉第 429 页，改用完整术语后将其排第一并读到原文。正确区分重复启用的 Command Sequence Error 与重复禁用必须成功且无动作，两项判据均满足 | 3 / 3 | 29.66 s |
| NVME21-001，控制器初始化和介质就绪 | 第 124 页的配置顺序和 Identify 时机答对；知道 Read 仍可能失败，缺少 DNR=0，亦未取到第 129 页。按原评分表不能整题通过 | 3 / 3 | 41.21 s |
| NVME21-028，指定 SSD 的就绪耗时 | 正确指出需要 CAP 读值和带时间戳的 CC.EN / CSTS.RDY 记录，没有编造实测值 | 2 / 4 | 23.80 s |

另保留初次只在提示中写预算的两次试跑。Pi 在脚本工具里批量请求，均突破了预期的六次服务端调用。因此正式试跑关闭批处理脚本入口，并在 MCP 服务端计数。原始事件和模型回答留在本地忽略目录。三题用于定位失败和检验工具边界；全库 Agent 回答正确率尚待单独测量。
