# SSD 工单签发

先读预取，只补查会改变动作的条款。处置、依据、验收各写一次。历史证据绑定同一对象和原时点。规则、现场观测与题面要求的批准分别核对。验收行包含实际对象、记录及每项通过条件，多项独立门槛可以分别列出。

- 已有充分证据时，按工单范围签发并指向其记录。使用题面给出的字段名和已解码字段。只有工单需要做位级解码且核到明确原图时才新增具体字节、位偏移或编码。
- 门铃：PRP1 是主机写的 Shadow Doorbell，PRP2 是控制器写的 EventIdx。公式、图示、实际槽位分别核对。涉及配置生效时按本次 Admin CQE 验收；失败先读该 CQE 的 SCT/SC。实测全范围时核对最远合法 SQ/CQ。
- 命令与数据：匹配原始提交及完成项，包括实际 SCT/SC。Fused 分别核两条 CQE，PCIe 共享 CQ 按 SQID/CID，NVMe-oF 按连接/CID，再核适用命令集。工单要求校验数据时，核对指定数据校验记录与预期值；成功 CQE 只证明命令结果。
- Steering Tag：只验普通报文的 TH/ST[7:0] 时，用目标请求的实测字段；验扩展时检查前缀。映射变更按工单确认责任方、版本和实测落点。
- MSI-X 改址或改数据验收：核对有效掩蔽、对应表项读回和真实解掩后同项发包的完整地址与数据。
