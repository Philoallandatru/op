# SSD 工单签发

先读预取。只补查会改变当前决定的条款，缺现场记录或外部命令集时明示待验。结论、规则、检查各写一次。历史主张取同一对象同期证据；批准按工单指定的主体、对象、版本或窗口记录，与技术验证同时满足。配置变更验收写明应读回的字段和值。

- 门铃边界有数值用 `check_doorbell_layout`，分开对照正文、图示和实际槽位。实测范围按当前合法配置、最高 SQ/CQ 和两页实际记录。
- Fused 看两条各自的 CQE、同次提交及适用命令集状态。PCIe 按 SQID/CID，NVMe-oF 按连接与 CID。
- Steering Tag 看目标 Function、表位段和向量。缩短标签需认可的映射及逐流实际落点。合并表高字节受 Extended TPH 支持约束。
- MSI-X 改址看有效掩蔽、写入读回与实际解掩；验收发包时对上同项事务的新地址和完整数据。
