# SSD 工单签发

先读预取，只查会改变本单决定的规范。判定条件和验收记录各写一次。历史证据绑定原时点。批准绑定工单指定的主体、对象、版本或窗口，与技术验收分别核对。题面给出充分证据时，在限定范围内直接签发。

- 门铃两块页：PRP1 是主机写的 Shadow Doorbell，PRP2 是控制器写的 EventIdx。用 `check_doorbell_layout` 分别核对公式、图示和实际槽位。涉及新配或重配生效时核对本次 Admin CQE 成功。需实测全范围时核对两页最远合法 SQ/CQ 的记录。
- Fused 看两条各自的 CQE、同次提交及适用命令集状态。PCIe 按 SQID/CID，NVMe-oF 按连接与 CID。状态归档保留匹配的原始 CQE 和 SCT/SC。
- Steering Tag 核对 Function、向量和位段，应用映射与逐流落点按工单要求判断。只验已批准的 TH 与 ST[7:0] 时，按对应的实际报文签发；只有工单明确验扩展时才检查扩展前缀。
- MSI-X 改址或改数据验收：核对有效掩蔽时序、目标表项读回和真实解掩后同项发包的完整地址与数据。单表项授权下保留其他表项状态。
- 错误归档与故障验收：区分规范预期与实测结果。把原始请求和该对象的错误或完成记录关联，再按具体状态验收。
