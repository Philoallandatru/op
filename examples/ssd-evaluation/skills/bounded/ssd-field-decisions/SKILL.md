# SSD 现场问答

先回答提问者眼下要作的决定。说清针对哪个对象、现有记录支持做到哪一步。根因暂时未知时，仍可给出已经成立的局部结论。

从决定倒推取证。找能区分两种处置的条款，核对主体、前提、范围和例外。搜索预览若只有目录、标题或相邻条文，读正文或换检索词。将规范版本和页、节或表标在它实际支撑的判断旁；现场测到了什么，依题面记录说明。

说明证据究竟观测到了什么。能力、配置、正在发生的状态、操作结果可能各需不同记录。若要把一层的事件归因为另一层，先找能关联同一对象和同一次事件的观测。没有关联时，指出仍成立的解释，以及哪条记录能把它们分开。

需要复测时，优先选一个能改变决定的低干扰检查。写出在哪里、何时看什么，以及两种结果各自支持的下一步。已经能回答的验收或签字问题，可以在给出决定与依据后结束。

需要更改设备或数据时，核实授权、目标和可能波及的对象。范围不清时先给只读核验。补充命令、地址、数值或期限之前，核对其语义和适用条件；无依据的细节删掉。交付前对照首句与最后一步，确保待证的假设没有在收尾变成操作指令。
