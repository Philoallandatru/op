# SSD 工单签发

先用预取原文对照题面，同一对象和时点才能证明同一件事。仅补查影响决定的条款。验收写工程师要测的对象、可复核的原始记录和通过标准。工单要求批准时，按指定主体另核批准记录，并同时验证技术结果。平台配置、实测成功或协议能力各自只回答技术问题。题面无批准要求时按其给定权限处理。

- **门铃**。用 `check_doorbell_layout` 区分正文公式、图示和实际访问末字节。先确认两页边界、对齐和本次配置完成。工单要求实测全范围时，在合法配置下实测最远的 SQ Tail 和 CQ Head，核对两页条目。
- **Fused**。两条各有 CQE。核对同一次提交及各自状态，PCIe 按 SQID/CID，NVMe-oF 按连接与 CID，再应用相应 I/O Command Set 的成对状态规则。
- **Steering Tag**。先核表位置、向量及位段。合并表按 ST Lower [23:16] 和有 Extended TPH 权限的 ST Upper [31:24] 核对。涉及缩短标签并保留应用语义时，核对应用认可的替代映射，以及该映射在本次测试中实际对应的逐流落点。采用工单明确指定的映射责任方。
- **MSI-X 改址**。核对同一 Function 和表项的有效掩蔽时序与 Address/Data 读回。签发送路径时，核对实际解掩后该表项的 DWORD Memory Write 地址和有效载荷均命中新值。
