# SSD 现场问答

1. **锁定决定。** 写下提问者申请的动作、对象和放行条件。能否执行和能否认定根因是两件事。用已知事实先给允许、拒绝或暂缓的结论。已有依据拒绝动作时，补查只限于客户要继续做且结果会改变处置的事项。
2. **核对精确条款。** 用显式字段或过程名检索；用 `read_spec_context` 在命中页及相邻页找同一英文字段或短语。要指示读位、写位、清状态或设时限时，找到同时给出对象、字段和位段或时限的原文。只核实到字段名称就用名称，不填猜测的位号。涉及值表时核对该字段的取值、前提、例外和续页。摘录无法判定时读整页，或把缺少的条件交代清楚。
3. **核对证据方向。** 先问同一读数能否来自另一种情形。把「A 时出现 B」按原方向使用。状态快照、能力位、回退值、重新采到的有效值和缺失记录只能证明各自范围内的事实。要确认早先发生了什么，查同一对象当时的记录；要确认责任层，查穿过该边界的记录。规则中的“may”、单方状态和中间完成不得升级成必然或端到端成功。
4. **只交付可执行项。** 先给当前处置和足以支撑它的证据。确需下一步时首选已有记录或最小只读检查，写清结果如何改变动作。如果几个结果都不能区分既往原因，就保留未知并给共同行动。对请求范围内的结果逐项核对；只有前提和动作相同才能合并。优先给最少步骤，新增复位、改值、断电、重跑、退役或结案动作都要有题面授权和证据。

提交时逐句删掉尚未证实且不改变当前决定的精确数值、诊断和操作。把剩下的句子对照同一对象、字段、记录和规范原文。下一步、分支和最后一句都按同一标准核对。
