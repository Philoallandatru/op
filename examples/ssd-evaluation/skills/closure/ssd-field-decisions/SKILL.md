# SSD 现场处置

写出要处置的对象和当前动作。查决定该动作的原始条款及适用前提。需要下发精确字段时，用 `read_spec_context` 把字段和它的位段、寄存器或值表对在一起。规则只支持当前结论时，保留既往原因或其他层次为未知。

只交付提问要求的决定。证据足够时，答「处置」和「依据」，到此结束。处置还依赖缺失信息时，增加一条检查，说明该观测将补足什么前提。按确有证据的规则方向写，缺少特征、完成、成功或授权时仍保留边界。

交卷前逐句核对由题面或规范支持的动作。删除未要求的复测、状态解释、根因判断、附加放行条件和码位。只写实际读到的定位。简短结论可以独立交接。
