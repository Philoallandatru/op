# SSD 工单签发

先读预取，只补查会改变动作的条款。每项签发给现场测量对象、可定位的原始记录和通过门槛。证据齐全就签发，并列出应随工单留存的已有记录，无需重做。暂缓时说明补证后可以重新评估的条件，已满足的门槛可直接引用。历史只用同对象、同次或有效覆盖区间证据。规范、实测和必要批准分别核对。

- Doorbell Buffer Config：分别核对公式、两页实际槽位、主机 PRP1 与控制器 PRP2 及本次 Admin SQE 的 PRP1/PRP2 与匹配的有效 Admin CQE。失败保留匹配有效相位及 SQID/CID 的 SCT/SC。全范围测试核对拟覆盖的最远 SQ Tail/CQ Head。
- Fused：分别核对当前两条原始 CQE，PCIe 共享 CQ 按 SQID/CID，消息传输按连接/CID。状态码与适用命令集一起核对。工单要求验证数据时，另留指定位置写后读回与预期模式的比对；成功 CQE 仅证明命令结果。
- Flush：同命名空间核对要覆盖的写命令完成记录早于 Flush 提交，并归档匹配的成功 Flush CQE。按实际缓存、命名空间与作用域交付。
- DNR：保留当前有效 CQE 的实际 SCT/SC、DNR 及原提交关联记录。DNR=1 拒绝以相同条件重提。后续按实际错误确认相关条件已改变，并满足工单要求的重试许可，再评估新提交；不得把复核结果预判为允许重试。
- Steering Tag：只在工单要求位级定位且原图明确时给出字节或位偏移。按实际报文核对普通 TH/ST 和所需扩展前缀。映射修改按工单对应的责任方、版本与真实落点核对，替代值也在批准范围内才可写。
- MSI-X：核对改写时的有效掩蔽、表项读回及真实解掩后在同项发包的完整地址和 32 位数据。
- IDLP：区分描述符单位换算、规范空闲计量窗口与现场另行定义的实测口径，按工单要求分别验收。

- 命令或队列标识可重用。日志与 CQE 用同一控制器、可验证的事件窗口、队列代次及有效相位或等效记录关联。CQE More=1 时查 Error Information Log，核对当前失败及同次新增条目，不用 SMART 总计数或仅相同 CID 归因。
