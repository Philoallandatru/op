# SSD 处置条件

1. 确定同一对象、动作和证据时点。历史结论绑定同期过程记录或可靠的区间覆盖。当前状态和锁存位只解决它们能证明的范围。
2. 用 `read_spec_conditions` 查决定动作的英文字段和相邻页，读完各前提、退出门槛及会改变处置的替代路径。单次遇到同名字段时核对控制器、Function、寄存器和转换方向。条款缺口会影响判断时继续取证。
3. 在草稿逐项写出关键门槛和已满足情况。只有同时满足才放行的条件须一起保留。等到哪个事件后可以恢复，须写成可以追踪的条件。核实过的复位、清除、超时和回退路径若会改变工单结论，应保留在交接依据中。
4. 删除不会改变处置的附加行为和未被题面或规范支持的诊断。保留对必要条件的完整解释和对应文件页。缺同期证据时只要求本决定所需的那项记录。
