# SSD 工单取证

1. 明确要判断的动作、对象和时点。历史判断要求同期记录或连续区间覆盖。复位或清除后的读数只用于其实际时点。
2. 先看已给的原文。缺处置条件时，用 `find_spec_conditions` 一次查关键英文名称及相邻条件；还缺决定性条款或跨页条件时，针对缺口用 `read_spec_conditions` 或 `read_spec_page`。条款足够便提交。
3. 签发前逐条核对当前动作、逻辑门槛（AND、OR、例外、恢复、作用域或先后顺序）、题面支持情况和 PDF 文件页。保留改变当前处置的条件和仍待核验的前提。只交付工单要求的最终 JSON。
