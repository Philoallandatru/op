# 脱敏现场工单盲测口径

每个测试题来自一个实际工单，保留原始问题、当时可用观测、脱敏追溯号和最后的工程师签发记录。后两项只给评审持有。选题时以同一事件和工单族去重，排除已用于写规则、调提示词或回归的工单。记录规范版次与本批签发依据；历史最终结论中晚于提问的证据不能倒灌到题面。

冻结工单、适用规范、模型、两组配置与预算后运行。交错配置顺序；每个配置只保留首答。评审看打乱且匿名的原答、当时证据、签发记录和可接受的等效证据。文件中隐藏配置、工具轨迹和耗时。遇到历史记录无法判定某答案的情况，交由实际工程师裁决，或者标待评并披露覆盖数。

| 判定 | 工程要求 |
| --- | --- |
| 原样可用 | 当前决定、实际核验对象、应查看的记录和通过条件齐全。已有同期证据充分就签；证据不足时可以明确暂缓并给出可执行的复验条件。 |
| 需修改 | 决定可保留，需补上工程师执行或签发所需的细节。 |
| 误导 | 会导致错放行、错暂缓、错归因或不必要的现场操作。记录具体建议和后果。 |
| 未交卷 | 超时或未得到有效答卷。 |

以计划题计原样可用率，以已交卷计误导率。公布有效人工判定的覆盖数。耗时使用交卷中位数和双方都交卷的同题差，运行异常另列敏感性结果。

将带 `origin: "field"` 和脱敏 `source_ref` 的题库 JSONL 放在忽略目录 `.local/` 下。工作台清单用 `caseBank` 指向该本地题库，`plan` 指向盲题，`runs` 与 `reviews` 指向运行记录及评分。先导出本地 JSON，再用 **导入报告** 打开。清单路径相对其所在目录。报告标题标明“现场工单”及评审来源。只有合成题、工具代码和公开规范定位进入项目仓库。
